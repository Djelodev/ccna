# CCNA SimuLab Academy
Prototype personnel en français. Voir AGENTS.md pour le cahier des charges.

## Démarrage
Node.js 22 recommandé.

```sh
npm install
npm run dev
```
Ouvrir http://localhost:3000. Vérifications : npm run typecheck et npm run build.

État : tableau de bord, module 1, premier cours/TP/quiz, aperçu du jour 2 et simulation WAN. Les autres modules sont des titres, pas des cours terminés. Les résultats restent dans localStorage ; aucun compte ni synchronisation. Ne pas publier de données personnelles. Authentification Supabase, tests et contenu complet à réaliser avant déploiement privé.
